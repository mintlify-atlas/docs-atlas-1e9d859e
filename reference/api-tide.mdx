`cscm.tide` provides two independent client modules for Belgian coastal water level data. `hic.py` wraps the Flemish Hydro Information Centre (HIC) KiWIS API via the `pywaterinfo` library, giving access to operational surge forecasts, astronomical tide predictions, and HW/LW extremes for the three canonical coastal stations. `mdk.py` wraps the Meetnet Vlaamse Banken (MDK) REST API v2 directly using `requests`, giving access to observed water-level time series for a broader set of six coastal monitoring stations including the offshore Westhinder platform.

Both modules express water levels in metres TAW (Tweede Algemene Waterpassing, the Belgian vertical datum), and both return results as `pandas.DataFrame` objects for seamless integration with analysis and plotting workflows.

## HIC module — `cscm.tide.hic`

### HicStation

```python
@dataclass(frozen=True)
class HicStation:
    code: str
    name: str
    station_id: str
    station_no: str
    latitude: float
    longitude: float
    ts_forecast_5min: str
    ts_astro_5min: str
    ts_forecast_hw: str
    ts_forecast_lw: str
    ts_astro_hw: str
    ts_astro_lw: str
    ts_observed_5min: Optional[str] = None
```

Immutable dataclass describing a HIC coastal forecasting station and the KiWIS time-series IDs required to retrieve each data product.

| Field | Type | Description |
|-------|------|-------------|
| `code` | str | Canonical 3-letter code (e.g. `"OST"`, `"NPT"`, `"ZLD"`) |
| `name` | str | Human-readable station name |
| `station_id` | str | HIC numerical station identifier |
| `station_no` | str | Official HIC station number (e.g. `"OST-1069"`) |
| `latitude` | float | WGS84 latitude |
| `longitude` | float | WGS84 longitude |
| `ts_forecast_5min` | str | KiWIS ts_id for the operational surge+tide forecast (KT-Last), 5-min resolution, m TAW |
| `ts_astro_5min` | str | KiWIS ts_id for the astronomical tide prediction (Astro.05), 5-min resolution, m TAW |
| `ts_forecast_hw` | str | KiWIS ts_id for forecast High Water extremes (KT-HW) |
| `ts_forecast_lw` | str | KiWIS ts_id for forecast Low Water extremes (KT-LW) |
| `ts_astro_hw` | str | KiWIS ts_id for astronomical High Water extremes (Astro.HW) |
| `ts_astro_lw` | str | KiWIS ts_id for astronomical Low Water extremes (Astro.LW) |
| `ts_observed_5min` | str \| None | KiWIS ts_id for 5-min gauge observations (O.05); `None` if unavailable |

#### `get_water_levels()`

```python
def get_water_levels(
    station_code: str,
    start_time: datetime,
    end_time: datetime,
    source: str = "forecast",
) -> pd.DataFrame
```

Fetches a 5-minute water-level time series in metres TAW.

<ParamField path="station_code" type="str" required>
  Station code (e.g. `"OST"`, `"NPT"`, `"ZLD"`).
</ParamField>

<ParamField path="start_time" type="datetime" required>
  Start of the query interval. Timezone-naive datetimes are treated as UTC.
</ParamField>

<ParamField path="end_time" type="datetime" required>
  End of the query interval.
</ParamField>

<ParamField path="source" type="str">
  Data product to retrieve. One of:
  - `"forecast"` — Operational hydrodynamic model including meteorological storm surge (KT-Last)
  - `"astro"` — Pure astronomical tide prediction (Astro.05)
  - `"observed"` — Historical 5-minute sensor observations (O.05); raises `ValueError` for stations without an observation time series

  Defaults to `"forecast"`.
</ParamField>

**Returns:** `pd.DataFrame` with columns:

| Column | Type | Description |
|--------|------|-------------|
| `timestamp` | datetime (UTC, tz-aware) | Sample time |
| `water_level_m_taw` | float | Water level in metres TAW |
| `station` | str | Station code |
| `source` | str | Data product used (`"forecast"`, `"astro"`, or `"observed"`) |

Returns an empty DataFrame with the same columns if the API returns no data.

#### `get_interpolated_curve()`

```python
def get_interpolated_curve(
    station_code: str,
    start_time: datetime,
    end_time: datetime,
    time_offset_minutes: float = 0.0,
    source: str = "forecast",
) -> pd.DataFrame
```

Fetches water levels and shifts the timestamps by `time_offset_minutes` to derive the tidal curve at a location that lags the reference station. For example, the beach at Bredene Strandpost 4 experiences tidal phases approximately 7 minutes after Oostende Haven, so you would call this method with `station_code="OST"` and `time_offset_minutes=7.0`.

The query is automatically extended at the start to ensure coverage after the shift: the API is queried from `start_time − offset` to `end_time − offset`, then the returned timestamps are shifted forward by `offset`.

<ParamField path="station_code" type="str" required>
  Base reference station code.
</ParamField>

<ParamField path="start_time" type="datetime" required>
  Desired start time at the target location.
</ParamField>

<ParamField path="end_time" type="datetime" required>
  Desired end time at the target location.
</ParamField>

<ParamField path="time_offset_minutes" type="float">
  Tidal phase lag in minutes. Positive values mean the target location's tide lags the reference station. Defaults to `0.0`.
</ParamField>

<ParamField path="source" type="str">
  `"forecast"` or `"astro"`. Defaults to `"forecast"`.
</ParamField>

**Returns:** `pd.DataFrame` with the same columns as `get_water_levels()`, plus an additional `target_offset_min` column recording the applied shift. Timestamps represent the shifted local time at the target location.

### MdkClient

```python
class MdkClient:
    def __init__(
        self,
        username: Optional[str] = None,
        password: Optional[str] = None,
        base_url: str = MDK_BASE_URL,
        session: Optional[requests.Session] = None,
        timeout: int = 30,
    )
```

Client for the Meetnet Vlaamse Banken REST API v2 (`https://api.meetnetvlaamsebanken.be`). Handles OAuth2 password-grant authentication, automatic token refresh, and converts raw API responses into `pandas.DataFrame` objects.

<ParamField path="username" type="str">
  MDK API username. If not provided, loaded from the `MDK_USERNAME` environment variable (or `.env` file).
</ParamField>

<ParamField path="password" type="str">
  MDK API password. If not provided, loaded from the `MDK_PASSWORD` environment variable (or `.env` file).
</ParamField>

<ParamField path="base_url" type="str">
  MDK API base URL. Defaults to `"https://api.meetnetvlaamsebanken.be"`.
</ParamField>

<ParamField path="session" type="requests.Session">
  Optional pre-configured `requests.Session`. Useful for testing with mocked responses or for customising SSL/proxy settings.
</ParamField>

<ParamField path="timeout" type="int">
  Request timeout in seconds. Defaults to `30`.
</ParamField>

#### `get_water_levels()`

```python
def get_water_levels(
    stations: Optional[List[str]] = None,
    start_time: Optional[Union[datetime, str]] = None,
    end_time: Optional[Union[datetime, str]] = None,
    in_meters: bool = True,
) -> pd.DataFrame
```

High-level convenience method. Resolves station codes to MDK `LocationParameterKey` strings, calls `get_data()`, and returns a tidy long-format DataFrame.

<ParamField path="stations" type="list[str]">
  Station codes to query (e.g. `["NPT", "OHM", "BLK"]`). Defaults to all six `COASTAL_TIDE_STATIONS` if `None`.
</ParamField>

<ParamField path="start_time" type="datetime | str">
  Start timestamp (UTC). Defaults to 24 hours before now.
</ParamField>

<ParamField path="end_time" type="datetime | str">
  End timestamp (UTC). Defaults to now.
</ParamField>

<ParamField path="in_meters" type="bool">
  If `True` (default), converts the raw cm TAW values to metres TAW. The output column is named `water_level_m_taw`. If `False`, the column is named `water_level_cm_taw`.
</ParamField>

**Returns:** `pd.DataFrame` sorted by `timestamp` then `station_code`, with columns:

| Column | Type | Description |
|--------|------|-------------|
| `timestamp` | datetime (UTC, tz-aware) | Sample time |
| `station_code` | str | Station code (e.g. `"OHM"`) |
| `station_name` | str | Human-readable station name |
| `water_level_m_taw` | float | Water level in metres TAW (or `water_level_cm_taw` if `in_meters=False`) |

def get_water_levels_pivot(

Convenience wrapper around `get_water_levels()` that pivots the result into a wide-format DataFrame with `timestamp` as the index and one column per station.

</ParamField>

<ParamField path="start_time" type="datetime | str">

<ParamField path="end_time" type="datetime | str">

<ParamField path="in_meters" type="bool">
