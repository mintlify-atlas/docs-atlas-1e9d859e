CSCM (Channel Swimmer Crossing Module) is a Python library and simulation engine built for ultra-distance open-water swimmers tackling the dynamic coastal currents of the North Sea. It solves **Zermelo's Navigation Problem** for human athletes — computing optimal headings, start times, and predicted trajectories by vectorially combining a swimmer's speed profile with real 1.5 km-resolution CMEMS tidal current forecasts.

## What CSCM Does

CSCM combines several specialised modules to support swim planning at every stage:

<CardGroup cols={3}>
  <Card title="Tidal Analysis" icon="water" href="/concepts/tidal-analysis">
    Per-cell PCA decomposes 2D current vectors onto the principal tidal flow axis and detects exact slack-water reversals.
  </Card>
  <Card title="Moon Cycles" icon="moon" href="/concepts/moon-cycles">
    NASA JPL ephemeris calculations identify synodic months and semi-diurnal tidal periods to partition data downloads.
  </Card>
  <Card title="CMEMS Data" icon="cloud-arrow-down" href="/data/cmems-retrieval">
    Automated lunar-cycle-partitioned downloads of 1.5 km / 15-minute resolution forecast currents from Copernicus Marine.
  </Card>
  <Card title="Tide Stations" icon="gauge" href="/data/tide-stations">
    Water level forecasts and tidal extremes from the HIC KiWIS and MDK Meetnet Vlaamse Banken APIs.
  </Card>
  <Card title="Trajectory Sim" icon="route" href="/simulation/overview">
    Step-by-step vector integration produces realistic predicted swim trajectories accounting for real current fields.
  </Card>
  <Card title="Wellknown Locations" icon="location-dot" href="/reference/wellknown">
    Built-in coordinates for Koksijde, Dover, Kingsgate, Orford Ness, and verified swimmer speed profiles.
  </Card>
</CardGroup>

## Get Started

<Steps>
  <Step title="Install CSCM with Poetry">
    Clone the repository and install dependencies using Poetry with Python 3.14.

    ```bash
    git clone https://github.com/marc-portier/cscm.git
    cd cscm
    poetry config virtualenvs.in-project true --local
    poetry env use python3.14
    poetry install
    ```
  </Step>
  <Step title="Configure your environment">
    Copy `.env.example` to `.env` and set your Copernicus Marine and MDK credentials.

    ```bash
    cp .env.example .env
    # Edit .env: add CMEMS_USERNAME, CMEMS_PASSWORD, MDK_USERNAME, MDK_PASSWORD
    ```
  </Step>
  <Step title="Download and analyse tidal data">
    Run the CMEMS pipeline to download current forecasts and generate per-cell tidal analysis databases.

    ```bash
    poetry run python -m cscm.current.cmems
    ```
  </Step>
  <Step title="Run a simulation">
    Place a YAML job file in `./data/simulation/` and execute the simulator to produce trajectory plots and GPX files.

    ```bash
    poetry run python -m cscm.simulation
    ```
  </Step>
</Steps>

<Note>
  CSCM requires **Python 3.14** and a valid Copernicus Marine Service (CMEMS) account to download current forecast data. See [Configuration](/configuration) for all environment variables.
</Note>
